## 🚀 Instalación

1. Clona este repositorio en tu máquina local:

    ```bash
    git clone https://github.com/FabianSilvaDev/Design-E-commerce.git
    ```

2. Abre los archivos `index.html` o `carrito.html` en tu navegador.

## 📄 Descripción

Este proyecto es un diseño de front-end para una tienda en línea. Está diseñado con una estructura básica que muestra cómo podría lucir un E-Commerce, implementando un diseño visual atractivo con HTML y CSS, y funcionalidades interactivas utilizando JavaScript puro.

## ✨ Características

- Diseño responsive
- Sección de carrito de compras
- Interacciones básicas utilizando JavaScript
